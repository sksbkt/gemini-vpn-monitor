# Conventions

> Auto-generated by codebase mapping | Brownfield Scan for open-gsd/gsd-core

## Coding Standards

### TypeScript & React
- Strict typing with interfaces defined in `src/vite-env.d.ts`.
- Functional components exclusively using React 18 hooks (`useState`, `useEffect`, `useRef`, `useCallback`).
- Animation loops and high-frequency real-time telemetry updates must bypass React state re-renders using `useRef` and direct canvas/uPlot manipulation.
- Props typed via explicit `interface` definitions.

### Electron IPC Patterns
- Main-to-Renderer events use `mainWindow.webContents.send('status-update', payload)`.
- Renderer-to-Main calls use `ipcRenderer.invoke(channel, args)` wrapped in `preload.js` returning Promises.
- Event listeners in `preload.js` must return an unsubscribe cleanup function `() => ipcRenderer.removeListener(channel, listener)` to prevent memory leaks in React `useEffect`.
- Strict sanitization on all user input passed to OS commands (e.g., regex `^[a-zA-Z0-9.-]+$` before `execFile`).

### UI & Styling Standards
- Draggable header regions must specify `-webkit-app-region: drag` with interactive buttons explicitly overriding `-webkit-app-region: no-drag`.
- Frameless window: `frame: false`, `transparent: true`.
- Dark HUD color palette:
  - Background: Glassmorphic translucent `#121826` / `rgba(18, 24, 38, 0.85)` with `backdrop-filter: blur(32px)`.
  - Normal Latency / Active: Cyber-green gradient / neon cyan (`#00f2fe`).
  - Timeouts / Drops: Crimson red (`#ff3366`) dropping sharply to `0ms`.
  - Offline / Error: Warning amber (`#ffb703`) or Crimson red (`#ff3366`).
