# Concerns & Technical Debt

> Auto-generated by codebase mapping | Brownfield Scan for open-gsd/gsd-core

## Known Bottlenecks & Migration Priorities

### 1. Window Frame & Drag Region Consistency
- **Issue**: Standard OS window frames conflict with the sleek glassmorphic HUD design.
- **Remediation (Phase 1)**: Configure `frame: false`, `transparent: true` on `BrowserWindow`, disable default OS title bars, and establish unified `-webkit-app-region: drag` / `no-drag` header regions in React.

### 2. High-Frequency State Re-rendering & Chart Lag
- **Issue**: Passing frequent ping updates (e.g. 1000ms or sub-second) directly through React state causes re-render overhead in charting libraries.
- **Remediation (Phase 2)**: Replace heavy DOM-based charting / legacy canvas implementations with `uPlot`, using an in-memory 60-second FIFO queue inside a `useRef` to achieve zero-delay 60 FPS Task Manager-style streaming with cyber-green gradient strokes and crimson red 0ms timeout drops.

### 3. Windows GPU Transparency Glitches
- Hardware acceleration can cause black borders on transparent windows on specific Windows GPU drivers; `app.disableHardwareAcceleration()` is in place where necessary.
