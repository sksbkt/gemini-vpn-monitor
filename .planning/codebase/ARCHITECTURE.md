## Architecture Overview

Gemini VPN Monitor operates as a two-process Electron application: a privileged Node.js **Main Process** that polls network metrics and Gemini endpoint health, and an unprivileged **Renderer Process** running React 18 and Vite with a glassmorphic desktop HUD widget.

## Process Responsibilities

### Main Process (`main.js`)
- Creates the desktop `BrowserWindow` with custom styling flags (`frame: false`, `transparent: true`).
- Manages persistent settings stored in `app.getPath('userData')/gemini-vpn-config.json`.
- Dispatches ping commands using `child_process.execFile` with strict input sanitization.
- Polls Gemini API endpoints using `https.get` to classify restriction state (`UNRESTRICTED`, `RESTRICTED`, `OFFLINE`).
- Exposes IPC handlers: `window:close`, `window:minimize`, `window:toggle-pin`, `settings:get`, `settings:save`.
- Streams telemetry to the renderer on `status-update`.

### Preload Script (`preload.js`)
- Secure boundary enforcing `contextIsolation`.
- Exposes typed window controller functions and event listeners via `contextBridge.exposeInMainWorld('api', ...)`.

### Renderer Layer (`src/`)
- Pure React 18 functional components with hooks (`useState`, `useEffect`, `useRef`).
- Direct canvas rendering via `PingOscilloscope` (migrating to zero-delay `uPlot`).
- Glassmorphic CSS with `backdrop-filter: blur(32px)`.
