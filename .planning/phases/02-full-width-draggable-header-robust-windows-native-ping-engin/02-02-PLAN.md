<objective>
Implement a robust, persistent Windows-native ICMP ping engine (pingEngine.js) using continuous child_process.spawn('ping', [target, '-t']), line buffering via readline, CP437/UTF-8 decoding, and precise CMD-matching regex parsing to eliminate process creation churn and false-positive 0ms drops, architected for multi-target dual-stream monitoring.

Purpose: Deliver rock-solid ICMP latency telemetry matching Windows Command Prompt accuracy without process spawning overhead or stream fragmentation drops.
Output: Persistent streaming service in pingEngine.js, automated unit test suite in test/test-ping-engine.js, updated package.json test runner script, and event-driven integration in main.js.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Settings IPC / User Input → Child Process Spawn | Untrusted or malformed target strings crossing into OS command execution. |
| Node.js Process → Windows OS Process Table | Child process spawn and termination lifecycle crossing into the OS kernel. |
| ping.exe Stdout Stream → Line Buffer Memory | Continuous unthrottled stdout streaming crossing into Node.js heap memory. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-03 | Remote Code Execution | pingEngine.js / main.js (child_process.spawn) | critical | mitigate | Pass target arguments as an array to child_process.spawn without shell invocation (shell: false), and validate targets against sanitizeTarget regex /^[a-zA-Z0-9.-]+$/ before starting stream. |
| T-02-04 | Denial of Service | pingEngine.js (process lifecycle) | high | mitigate | Implement explicit stop() method calling child.kill(), register process error and exit listeners, and hook app.on('before-quit') in main.js to prevent orphaned zombie ping processes. |
| T-02-05 | Denial of Service | pingEngine.js (stdout stream buffering) | medium | mitigate | Use Node.js readline with crlfDelay: Infinity to parse lines immediately on CRLF events without unbounded memory accumulation. |
| T-02-SC | Tampering | npm dependencies | high | mitigate | Package legitimacy gate verified; strictly zero new third-party dependencies installed (uses native Node.js child_process, events, and readline). |
</threat_model>
