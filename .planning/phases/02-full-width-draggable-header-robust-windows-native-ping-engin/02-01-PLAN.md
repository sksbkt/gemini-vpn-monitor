<objective>
Refactor the desktop window top header to provide full-width edge-to-edge draggable ergonomics (Discord-style dragging) across the top border while strictly isolating interactive control buttons (#closeBtn, #minBtn, #settingsBtn, #pinBtn) with -webkit-app-region: no-drag !important and pointer-events: none on child SVGs.

Purpose: Deliver effortless desktop widget repositioning across multiple displays without accidental window drag hijacking or missed control button clicks.
Output: Refined Discord-style drag header structure in src/components/Header.tsx, updated drag and control isolation CSS rules in styles.css, and expanded automated static analysis assertions in test/test-shell-config.js.
</objective>
