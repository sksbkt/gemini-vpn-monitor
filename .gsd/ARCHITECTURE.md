## Overview

Gemini VPN Monitor is a real-time, desktop glassmorphic widget built on Electron with a modern Vite + React + TypeScript frontend. It continuously monitors network latency (ping to `4.2.2.4`) and Google Gemini API geo-restriction availability (`generativelanguage.googleapis.com`), streaming telemetry across an IPC context bridge to a 60 FPS HTML5 Canvas latency oscilloscope and a responsive 2x2 metrics grid.

## Data Flow

1. **Application Launch:** `main.js:createWindow` instantiates a frameless, transparent 360x345 window with hardware acceleration disabled (to avoid Windows GPU transparent window glitches) and loads `dist/index.html` (or `process.env.VITE_DEV_SERVER_URL` in dev).
2. **Ping Polling Loop:**
   - Every ~1000ms, `main.js:runPing` executes `ping 4.2.2.4 -n 1 -w 800`.
   - Latency parsed via regex `time[=<](\d+)ms` or `time<1 ms`.
   - History buffer tracks moving average and packet loss percentage over recent 10 samples.
3. **Gemini Status Polling Loop:**
   - Every 6000ms, `main.js:checkGemini` sends an HTTPS GET to `generativelanguage.googleapis.com`.
   - Resolves `RESTRICTED`, `UNRESTRICTED`, or `OFFLINE`.
4. **IPC Dispatch:** `main.js` broadcasts `status-update` payload `{ ping, avgPing, lossPct, history, status, server, timestamp }` to `mainWindow.webContents`.
5. **Renderer Telemetry Ingestion:**
   - `src/App.tsx` receives telemetry in its `useEffect` subscription.
   - Updates `StatusPill` and `MetricsGrid` state.
   - Dispatches new `latestPing` record to `PingOscilloscope`.
6. **60 FPS Oscilloscope Stream:**
   - `PingOscilloscope` ingests incoming ping ticks into its `useRef` rolling FIFO queue.
   - `requestAnimationFrame` continuously shifts time from right to left with a 2.0s playback delay.
   - Timeouts plunge directly down to the visible 0ms baseline gridline in glowing neon red (`#ff3366`).
   - Normal latency renders as glowing neon cyan (`#00f2fe`).
   - Interactive hover marker snaps to the curve with tooltips.
