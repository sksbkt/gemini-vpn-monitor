## Data Flow

1. **Application Launch:** `main.js:createWindow` instantiates a frameless, transparent 360x345 window with hardware acceleration disabled (to avoid Windows GPU transparent window glitches).
2. **Ping Polling Loop:**
   - Every ~1000ms, `main.js:runPing` executes `ping 4.2.2.4 -n 1 -w 800`.
   - Latency parsed via regex `time[=<](\d+)ms` or `time<1 ms`.
   - Results pushed to rolling history (max 18 items) to calculate moving average and packet loss percentage over the last 10 samples.
3. **Gemini Status Polling Loop:**
   - Every 6000ms, `main.js:checkGemini` sends an HTTPS GET to `https://generativelanguage.googleapis.com/v1beta/models?key=vpn_check_ping`.
   - Detects `RESTRICTED` if response contains `User location is not supported` or `API usage not available in your region`.
   - Detects `UNRESTRICTED` if HTTP 200 or `API_KEY_INVALID` / `API key not valid` (indicating connection reached Gemini endpoint unimpeded).
   - Detects `OFFLINE` on request error or timeout.
4. **IPC Dispatch:** `main.js` sends `status-update` payload `{ ping, avgPing, lossPct, history, status, server, timestamp }` to `mainWindow.webContents`.
5. **Renderer Ingestion & Conveyor Waveform:**
   - `renderer.js` receives payload, updates status pill text/dot and 2x2 metric card texts.
   - Appends record to rolling `points` array and sorts by timestamp.
   - `requestAnimationFrame(animate)` maps time to horizontal screen X with a 2.0s playback delay (`SVG_W / WINDOW_MS`).
   - SVG `<path>` elements (`pathFill`, `glowWideCyan`, `coreStrokeCyan`, `glowWideRed`, `coreStrokeRed`) updated directly via `setAttribute('d', ...)`.
   - Timeouts render as direct drops to baseline `y = 76`.
