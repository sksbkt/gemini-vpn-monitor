# Plan 3.2: Full Production Build, Process Launch Testing, and Milestone Audit

## Objective
Execute the production build of the Vite frontend, run a non-blocking Electron process smoke launch to ensure no startup crashes or syntax regressions, and verify all SPEC must-haves before completing milestone v1.2.

## Context
- .gsd/SPEC.md
- .gsd/ROADMAP.md
- package.json
- main.js
- dist/index.html

## Tasks

<task type="auto">
  <name>Run production build and verify bundled assets</name>
  <files>dist/index.html, dist/assets/</files>
  <action>
    1. Run `npm run build` (`tsc && vite build`).
    2. Confirm `dist/index.html` exists and references relative assets (`./assets/...`).
    3. Confirm bundled JS and CSS contain settings modal components, handlers, and SVG icons.
  </action>
  <verify>node -e "const fs = require('fs'); const html = fs.readFileSync('dist/index.html', 'utf8'); if (html.includes('assets/index') && fs.existsSync('dist/assets')) console.log('BUILD_DIST_VERIFIED'); else process.exit(1);"</verify>
  <done>Production bundle exists, properly linked with relative paths, and passes asset integrity check.</done>
</task>

<task type="auto">
  <name>Perform Electron process launch smoke test and milestone audit</name>
  <files>main.js, package.json</files>
  <action>
    1. Launch Electron with `electron . --smoke-test` or timed launch test (2 seconds) to ensure `main.js`, `preload.js`, and `dist/index.html` initialize without unhandled exceptions or GPU crashes.
    2. Audit all SPEC must-haves:
       - Persistent config file management (`gemini-vpn-config.json`).
       - Strict regex shell sanitization.
       - Dynamic poller reconfiguration.
       - Glassmorphic modal UI with presets and slider.
       - Clean TypeScript types and zero build warnings.
  </action>
  <verify>node -e "const cp = require('child_process'); const p = cp.spawn('npx.cmd', ['electron', '-v']); p.on('exit', (code) => process.exit(code || 0));"</verify>
  <done>Electron environment responds cleanly and milestone requirements are 100% verified.</done>
</task>

## Success Criteria
- [ ] Production build succeeds with all assets compiled.
- [ ] Electron environment launches cleanly without runtime exceptions.
- [ ] All SPEC must-haves verified with zero regressions.
