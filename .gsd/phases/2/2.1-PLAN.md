# Plan 2.1: Modular HUD Components & Robust IPC Subscription Lifecycle

<task type="auto">
  <name>Enhance IPC listener lifecycle and compose App.tsx</name>
  <files>preload.js, src/vite-env.d.ts, src/App.tsx</files>
  <action>
    1. Update `preload.js` so that `onUpdate` returns an unsubscribe callback:
       ```js
       onUpdate: (callback) => {
         const subscription = (_event, data) => callback(data);
         ipcRenderer.on('status-update', subscription);
         return () => ipcRenderer.removeListener('status-update', subscription);
       }
       ```
    2. Update `src/vite-env.d.ts` to reflect the cleanup return type: `onUpdate: (callback: ...) => (() => void) | void`.
    3. Refactor `src/App.tsx` to cleanly compose `Header`, `StatusPill`, `PingOscilloscope`, and `MetricsGrid`, returning the unsubscribe handler in its `useEffect` hook.
  </action>
