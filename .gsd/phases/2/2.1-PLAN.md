# Plan 2.1: Settings Modal Component and State Management

## Objective
Build `SettingsModal.tsx` as a React component managing custom host/IP input, DNS preset buttons (`4.2.2.4`, `1.1.1.1`, `8.8.8.8`, `9.9.9.9`), ping interval slider (500ms - 3000ms), and reset action. Integrate the modal into `App.tsx` and add a settings gear button in `Header.tsx`.

## Context
- .gsd/SPEC.md
- .gsd/ROADMAP.md
- src/components/Header.tsx
- src/App.tsx
- src/vite-env.d.ts
- main.js

## Tasks

<task type="auto">
  <name>Create SettingsModal.tsx with presets, validation, and IPC integration</name>
  <files>src/components/SettingsModal.tsx</files>
  <action>
    Create `src/components/SettingsModal.tsx` that:
    1. Accepts props: `isOpen: boolean; onClose: () => void; currentTarget: string; onSaveSuccess: (newTarget: string) => void`.
    2. Fetches active settings on open via `window.api.getSettings()`.
    3. Provides DNS presets:
       - `Level3 (4.2.2.4)`
       - `Cloudflare (1.1.1.1)`
       - `Google (8.8.8.8)`
       - `Quad9 (9.9.9.9)`
       Clicking a preset populates the target input and updates state.
    4. Validates custom host/IP with regex `/^[a-zA-Z0-9.-]+$/`. Disables save button or displays an inline error if invalid.
    5. Includes a range slider for `pingIntervalMs` between 500ms and 3000ms with a step of 250ms and live readout.
    6. "Reset to Defaults" button restoring `4.2.2.4`, `1000ms`, `800ms`.
    7. Calls `window.api.saveSettings()` on submit, displays error if rejected, and closes modal on success.
    8. Handles Escape key to close the modal.
  </action>
  <verify>npx tsc --noEmit</verify>
  <done>`src/components/SettingsModal.tsx` compiles with zero TypeScript errors.</done>
</task>
