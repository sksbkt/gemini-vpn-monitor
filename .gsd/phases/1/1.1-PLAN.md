# Plan 1.1: Dependencies, TypeScript, and Vite Configuration

## Objective
Establish the modern build infrastructure for the Electron renderer by declaring required React, TypeScript, and Vite packages in `package.json`, and configuring `tsconfig.json` and `vite.config.ts` for relative Electron bundling.

## Context
- .gsd/SPEC.md
- .gsd/ROADMAP.md
- .gsd/ARCHITECTURE.md
- package.json

## Tasks

<task type="auto">
  <name>Configure package.json dependencies and scripts</name>
  <files>package.json</files>
  <action>
    Update `package.json`:
    - Add production dependencies: `react` (^18.2.0), `react-dom` (^18.2.0), `uplot` (^1.6.32).
    - Add devDependencies: `@types/react` (^18.2.0), `@types/react-dom` (^18.2.0), `@vitejs/plugin-react` (^4.2.0), `typescript` (^5.3.0), `vite` (^5.1.0), while preserving `electron` (^28.0.0).
    - Add scripts:
      - `"dev": "vite"`
      - `"build": "tsc && vite build"`
      - `"preview": "vite preview"`
      - `"start": "electron ."`
    - Run `npm install` to resolve all packages and lockfile.
  </action>
  <verify>npm list --depth=0</verify>
  <done>`package.json` contains `react`, `react-dom`, `uplot`, `vite`, `typescript`, `@vitejs/plugin-react`, and `npm list` exits with 0.</done>
</task>

<task type="auto">
  <name>Create TypeScript and Vite configuration files</name>
  <files>tsconfig.json, vite.config.ts</files>
  <action>
    1. Create `tsconfig.json` configured for:
       - `"target": "ES2020"`, `"lib": ["ES2020", "DOM", "DOM.Iterable"]`
       - `"module": "ESNext"`, `"moduleResolution": "bundler"`
       - `"jsx": "react-jsx"`
       - `"strict": true`, `"skipLibCheck": true`
       - `"include": ["src"]`
    2. Create `vite.config.ts`:
       - Import `defineConfig` from `'vite'` and `react` from `'@vitejs/plugin-react'`.
       - Set `base: './'` so generated bundle assets resolve via relative paths inside Electron `loadFile`.
       - Set build output directory to `dist`.
  </action>
  <verify>Get-ChildItem tsconfig.json, vite.config.ts</verify>
  <done>`tsconfig.json` and `vite.config.ts` exist with correct JSX and `base: './'` configurations.</done>
</task>

## Success Criteria
- [ ] `package.json` specifies all necessary dependencies and build scripts.
- [ ] `tsconfig.json` passes TypeScript configuration checks.
- [ ] `vite.config.ts` is configured with `base: './'` for Electron compatibility.
