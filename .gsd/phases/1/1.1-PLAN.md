# Plan 1.1: Persistent Settings Store and Sanitized IPC Handlers

## Objective
Establish a persistent JSON configuration store in Electron's `userData` directory with safe defaults (`4.2.2.4`, `1000ms`, `800ms`), implement strict shell injection sanitization, register `settings:get` and `settings:save` IPC handlers, and expose them through `preload.js` with TypeScript typings.

## Context
- .gsd/SPEC.md
- .gsd/ROADMAP.md
- .gsd/ARCHITECTURE.md
- main.js
- preload.js
- src/vite-env.d.ts

## Tasks

<task type="auto">
  <name>Implement config persistence and shell sanitization in main.js</name>
  <files>main.js</files>
  <action>
    In `main.js`:
    1. Define default settings object:
       `DEFAULT_SETTINGS = { pingTarget: '4.2.2.4', pingIntervalMs: 1000, pingTimeoutMs: 800, isPinned: false }`
    2. Implement `getConfigPath()` returning `path.join(app.getPath('userData'), 'gemini-vpn-config.json')`.
    3. Implement `loadSettings()`: Read and parse JSON if file exists, validate keys, merge with `DEFAULT_SETTINGS`, fallback to defaults on error.
    4. Implement `saveSettings(newSettings)`:
       - Validate `pingTarget` with regex `/^[a-zA-Z0-9.-]+$/` (blocking any shell metacharacters like `;`, `&`, `|`, `` ` ``, `$`).
       - Validate `pingIntervalMs` (clamped between 500 and 5000).
       - Validate `pingTimeoutMs` (clamped between 300 and 3000).
       - Write formatted JSON atomically to disk.
  </action>
  <verify>node -e "const fs = require('fs'); const re = /^[a-zA-Z0-9.-]+$/; console.log(re.test('4.2.2.4') && re.test('google.com') && !re.test('4.2.2.4; whoami') ? 'VALIDATION_PASS' : 'FAIL')"</verify>
  <done>Regex sanitization correctly passes valid hosts and rejects shell injection attempts.</done>
</task>
